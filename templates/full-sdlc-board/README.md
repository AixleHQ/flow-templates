# Full SDLC board

A nineteen-column board covering design, tech design, development, QA, UAT and release.

Columns: Backlog, Ready for Design, In Design, Design Review, Ready for Tech Design, In Tech Design, Tech Design Review, Ready for Dev, In Development, Code Review, Ready for QA, In QA, QA Approved, Ready for UAT, In UAT, UAT Approved, Ready for Release, In Release, Done.

Installing it into a project that already has a board adds only the columns that board does not have yet. Changing a board needs the project owner.
